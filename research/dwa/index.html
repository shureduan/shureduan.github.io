Multimodal Temporal Segmentation with Dynamic Attention Windows Using Visual and Vibration Signals

Jingxuan Duan · Carnegie Mellon University
Advisor: Prof. Pingbo Tang

DWA combines video with physical sensor signals for temporal action segmentation. It resizes the sensor attention window according to local signal shape.

Code · Pretrained weights · Reproduction guide

Datasets

TGIF: worker-state recognition

Video + machine vibration. Three states: idle, sewing and handling.

WEAR: outdoor activity recognition

Egocentric video + four 50 Hz, 3-axis accelerometers. Eighteen exercise classes plus background.

Mean CPU forward time decreases from 1.266 s to 0.757 s: 40.2% less time (1.67× speedup) over DWA v3 in this measurement.

Method

The latest WEAR implementation uses three steps:

  1. Signal features: AC-RMS envelopes and ordered slope histograms describe activity strength and coarse signal shape.
  2. Window resizing: contract at signal changes; expand through contiguous regions with similar shape.
  3. One-way attention: video queries attend to raw sensor keys/values in the selected window. A shared MS-TCN refines predictions over two rounds, followed by background calibration.
